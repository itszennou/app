Rate this project

Chrono Overhaul rebuilds the game's time system from the ground up. Instead of a simple pause-and-rewind gimmick, this mod introduces layered timelines, paradox-triggered events, and a full UI overhaul for tracking temporal state.

What's Included

  • Rewind system with configurable time-window limits
  • Freeze-frame puzzle mechanics with 40+ new encounter types
  • Paradox detection system that reshapes the environment when timelines conflict
  • Full UI rework for the temporal HUD
  • Compatible save-game migration tool for existing playthroughs

Installation

Extract the archive into your game's /mods directory. Requires the base game updated to the latest patch. Full instructions are included in the archive's README.

Compatibility Notes

This is a total conversion mod — it is not compatible with other mods that modify core time mechanics. Conflicts with UI-overhaul mods are possible; check the comments section for community-reported compatibility notes.

Detailed setup, configuration, and troubleshooting reference for Chrono Overhaul. This section is maintained separately from the version changelog and covers usage beyond the basic README.

Configuration

Time-window limits, paradox sensitivity, and HUD layout can be adjusted in config/chrono_settings.ini. Each option is documented inline with default values and safe ranges.

Save Compatibility

Existing saves are migrated automatically on first load after install. Back up your save folder before updating major versions — migration is one-way and cannot be reversed by downgrading the mod.

Known Issues

  • Paradox events may not trigger correctly in split-screen co-op mode
  • Rewind HUD can overlap with other UI-overhaul mods; disable HUD scaling if this occurs
  • Very long rewind windows (60s+) may cause a brief stutter on lower-end hardware

API for Other Mods

Chrono Overhaul exposes a small hook API for mods that want to read or react to time-state changes. See docs/api_reference.md in the archive for available events and functions.
